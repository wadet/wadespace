## 🎮 Quick Commands

```bash
# First time?
source venv/bin/activate          # Activate environment
pip install pygame                # Install dependencies

# Ready to play?
python -m src.ui_main             # Launch Pygame UI
python -m src.main                # Launch text mode

# Want to verify?
python verify_ui.py               # Test installation
python -m pytest tests/ -v        # Run all tests

# Need help?
cat INSTALL.md                    # See installation guide
```
